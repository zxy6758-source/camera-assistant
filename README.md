# 구도 도우미 (camera-assistant)

폰을 거치대에 세워 두고 후면 카메라로 찍을 때, **사람이 제대로 나오는지·배경 비중이 적당한지**를
실시간으로 판정해 **음성으로 안내**하는 웹앱입니다. 음성 명령(스마일/김치/촬영/찰칵)으로 촬영도 합니다.

## 중요한 제약
- 카메라는 한 번에 한 앱만 쓸 수 있습니다. **삼성 카메라 앱과 동시에 실행할 수 없고**, 이 앱이 카메라를 직접 사용합니다.
  따라서 삼성 카메라 앱의 화질 처리(HDR 등)는 적용되지 않습니다.
- 후면 카메라일 때 화면은 피사체 반대편을 향하므로 **음성 안내가 핵심**입니다. (볼륨을 올려 두세요)
- 카메라 접근은 **HTTPS**(또는 localhost)에서만 됩니다. → GitHub Pages 등에 올려서 폰 Chrome으로 접속하세요.
- 음성 인식은 브라우저(Android Chrome)의 Web Speech API를 쓰며 네트워크가 필요합니다.
- 사진은 브라우저 다운로드 폴더에 저장됩니다. 동영상은 소리 없이 저장됩니다(마이크 충돌 회피).

## 사용
1. 폰 Chrome으로 페이지 접속 → 「시작」 → 카메라/마이크 허용
2. 촬영 범위(전신/상반신), 배경 비중(넓게/보통/인물 중심) 선택
3. 안내에 따라 위치 조정 → “좋아요. 구도 완성”이 나오면 “김치!”

## 판정 항목
머리·발·옆 잘림, 인물 크기(배경 비중), 좌우 위치(화면 기준), 위쪽 여백, 역광, 인원 수.
임계값은 `logic.js`의 경험적 수치이며 `BG_PRESETS` 등에서 조정할 수 있습니다.

## 개발
```
node --test test/logic.test.mjs     # 판정 로직 단위 테스트
python3 -m http.server              # 로컬 확인(PC 브라우저, localhost)
```
포즈 추정: MediaPipe Tasks Vision `PoseLandmarker`(lite), CDN에서 불러옵니다.
